# Run original ALE v1

**Use the published `v1` tag, legacy images, and fresh logs together.** The tag
points to `d9abc0734b56ea34116c5bfcbdd0b808269ab9e2`. It preserves the original
task requirements, software and grading, including tasks retired or converted
to open-source workflows in v1.1. Original licensed workflows still require
their original software and valid licenses. Do not substitute v1.1 images,
data, task code or results.

## Set up a separate checkout

Run these commands in a persistent disk-backed directory, separate from your
v1.1 checkout:

```bash
git clone --branch v1 https://github.com/rdi-berkeley/agents-last-exam.git agents-last-exam-v1
cd agents-last-exam-v1
git rev-parse HEAD
uv sync --all-packages
cp -n secret/.env.example secret/.env
cp -n secret/eval_time/openai.env.example secret/eval_time/openai.env
cp example_exp.yaml my_v1_experiment.yaml
```

Fill in the agent/provider credentials in `secret/.env` and the evaluator
credentials required by the selected v1 tasks. Keep evaluator credentials
separate from agent presets. Choose one provider below.

## Google Cloud

Follow the [cloud setup](../quickstart.md) for authentication, project, service
account and restricted networking, but **copy these legacy images instead of
the v1.1 images**. Both are retained in project `agenthle-488519`:

```bash
for image in ale-ubuntu22 ale-win10; do
  gcloud compute images create "$image" \
    --project="$GCP_PROJECT" \
    --source-image="$image" \
    --source-image-project=agenthle-488519
done
```

Set `GCP_PROJECT` and `GCP_SA_KEY` in `secret/.env`. The tagged
`configs/environments/environment_gcloud.yaml` already selects the legacy
`ale-ubuntu22` and `ale-win10` image names. Copying these two images covers
**nonlicensed snapshots only**. The full tagged task list additionally requires
the original licensed image profiles, installed software and valid licenses.
Configure those licensed snapshots before selecting the full list; the two
image copies alone do not make every v1 task runnable.

## Local QEMU/KVM

Use a Linux host with Docker and `/dev/kvm`. Before downloading or launching,
check the resolved `qemu.root` with `findmnt -T` and `df -h`, available RAM
with `free -h`, and running/retained VMs with `docker ps` and
`ps -eo pid,comm,args`. Use persistent disk, never host `/tmp` or `/dev/shm`;
budget for all guests, base disks and growing overlays.

```bash
cp configs/environments/qemu.yaml my_qemu_v1.yaml
```

Keep the legacy `disk_source` values in this copy:

| Snapshot | `qemu.disk_source` |
| --- | --- |
| `cpu-free-ubuntu` | `hf://agents-last-exam/ale-images-qcow2/ale-ubuntu22.qcow2` |
| `cpu-free` | `hf://agents-last-exam/ale-images-qcow2/ale-win10.qcow2` |

Add this field inside **each** snapshot's `qemu:` block:

```yaml
hf_revision: 40ba46b348a684b7d1b34d18e308aed54737f41a
```

v1 uses `hf_revision`, **not `image_revision`**. The pin selects the retained
legacy files in the [QEMU dataset](https://huggingface.co/datasets/agents-last-exam/ale-images-qcow2/tree/40ba46b348a684b7d1b34d18e308aed54737f41a).
Keep `task_data_source: baked_in_sandbox` and `output_path: null`. Set the
experiment's `environment: my_qemu_v1.yaml`. QEMU supports the tagged
`selected_tasks/cpu_unlicensed.txt` list, not v1.1's `cpu.txt`.

## Configure and run

In `my_v1_experiment.yaml`, set `name: my_v1_experiment` and a fresh
`output.root: .logs/ale-v1`. Never point v1 at v1.1 logs or run the v1.1 log
upgrade helper on this new run. Keep `concurrency: 1` initially and
`cleanup_mode: delete`; environment `output_path: null` disables bulk output
collection while run records and trajectories are still collected.

Start with the example's `tasks: selected_tasks/hello_both.txt`. After the
smoke, use `selected_tasks/cpu_unlicensed.txt` for QEMU or nonlicensed CPU cloud
runs. Select the tagged `selected_tasks/full.txt` only after provisioning all
required snapshots, including the original licensed image profiles, software
and licenses, plus GPU resources where required.

```bash
uv run python -m ale_run run my_v1_experiment.yaml --dry-run
uv run python -m ale_run run my_v1_experiment.yaml
```

These runs measure v1's original requirements. Report them as v1, separately
from the [122-task v1.1 release](v1.1.md).
