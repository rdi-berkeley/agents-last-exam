# ALE v1.1 task review

The table covers all **57 modified active tasks** in the [upgrade map](../../releases/v1.1/upgrade.json); 65 active tasks are unchanged and 30 retirements are listed separately. The map records task source identities. Published assets are pinned in the [asset manifest](../../releases/v1.1/assets.json).

The table records task decisions and the scope and limits of component checks. It does not certify a complete agent rerun of the release. Published Linux/Windows images pass fresh boot and runtime checks; distributed data matches the frozen manifest. See the [release guide](v1.1.md) for matching code, data and environment requirements.

**Source** means release code changes; **Data** means published replacement or exclusion data; **Retained** means the reviewed materials stay in place. Retained materials do not change a task's rerun classification. **Verified** identifies the specific checks that passed; **Reviewed** indicates a retained decision without a new execution check. These are contract, component and selected simulation checks, not a rerun of every task by an agent.
