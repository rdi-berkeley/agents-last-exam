# ALE v1.1 task update inventory

The repair/audit scope contains 59 original tasks plus the NSCLC evaluator-status
follow-up (60 distinct task IDs). This is not 60 newly edited tasks relative to
current main. Existing upstream fixes and already-matching HF data are carried
forward. The selected full benchmark remains 152 tasks.

`Source files` counts task-local files changed by this PR relative to main.
`Data publication` identifies input/software/reference payload changes relative
to the previous HF default heads; `unchanged` does not mean the task was never
repaired. Shared runtime/provider fixes are not counted as task-local changes.
All-only variants are excluded from the selected distribution.

The 59 tasks have recorded Kimi Code/K3 max VM runs and individual outcome
reviews, followed by targeted reruns for the approved post-review corrections.
All 99 Docker-supported tasks have paired VM/Docker reviews. These reviews are
not a guarantee of perfect task design or solver success. Final IDP binary and
resource-disclosure deltas retain their separate validation scope; NSCLC's
original Docker OOM remains failed/null, not a successful rerun. See the
[release guide](v1.1.md) for evidence and limitations.
