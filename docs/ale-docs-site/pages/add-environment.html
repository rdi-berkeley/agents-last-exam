Add an environment

A new backend (another cloud, or your own hardware) is a Provider: it creates or attaches a sandbox and hands the framework a live cua-server endpoint. The shipped implementations are gcloud, docker, qemu, and static.

Roadmap

  • Local VMware. Add a managed VMware lifecycle alongside the existing local QEMU/KVM VM provider.
  • More clouds: Azure, AWS, Aliyun. The same ephemeral-VM lifecycle on other providers, for capacity and region choice.
Reference implementations
Implement the small Provider contract (acquire / release / open_session). Use providers/gcloud.py for remote VMs, providers/docker.py for local containers, providers/qemu.py for local VMs, or providers/static.py for an existing endpoint. The contract is on Sandbox & provider.
