# Constrained spin-triangle gate synthesis

This designed quantum-control physics problem supplies twelve sets of three-spin
Hamiltonians and target unitaries. It requires a shared calibration for four
local frames per spin, fixed-duration pulses, and at most one active exchange
bond at a time. The gate, all three bond leakage integrals, and the linear and
quadratic coefficients of ten independently weighted noise channels are tested.

The public task is defined by `TASK_SPEC` and `CALCULUS_SPEC` in
`scripts/build_fixtures.py` and the standalone `scripts/verify_outputs.py`.
All grading conditions are visible. The host regenerates canonical inputs
for evaluation, so changing a staged input or checker cannot change the score.

## Control and scoring contract

| Quantity | Constraint |
| --- | --- |
| Pulse count | 2 through 96 per scenario |
| Local frames | One U3 calibration per spin, followed by I, X, Y, or Z |
| Pulse duration | Exactly 0.25 |
| Exchange amplitude | Absolute value at most 0.25 |
| Amplitude modulation | One shared magnitude per bond, with sign and on/off control |
| Simultaneous driven bonds | At most one |
| Bond action in every scenario | At least 0.05 on every bond |
| Gate infidelity | At most 1e-8 |
| Maximum bond leakage norm | At most 1e-8 |
| Maximum of 10 linear noise coefficients | At most 1e-8 |
| Maximum of 55 quadratic noise coefficients | At most 1e-8 |

The score is the fraction of fully passing scenarios. A schedule must implement
the requested gate as well as meet the error requirements to earn completion
credit. The checker also reports an unscored weighted diagnostic: gate 0.80,
leakage 0.08, first order 0.06, and second order 0.06. Always retain both numbers
in evaluation reports. Completion scores are not directly comparable to older
versions that used the weighted diagnostic as their benchmark score.

Noise coefficients include the supplied correlated operator and all nine
laboratory-frame single-spin Pauli operators, with cross-channel terms at
second order. The error functionals use the idealized frame-level convention
in the task specification. They are not a simulation of finite-width frame
switches or a full interaction-picture robustness guarantee.

## Feasibility and author verification

The generator constructs a 96-pulse witness from a balanced multiset of 16
frames per bond, interleaved using a fixed scenario-specific permutation, and
its reverse. Every scenario has noncommuting drift and full-rank exchange.
A shared local calibration brings the operators into a
frame in which group averaging cancels leakage and linear noise. Reversing
the sequence cancels the second-order coefficients, including mixed terms.
The target is generated by the ordered matrix exponentials of this feasible
schedule. The evaluator accepts any schedule satisfying the contract.

Author witnesses and the generator are never staged in the agent environment.
The two incomplete-calibration baselines are hand-built diagnostics, not
independent agent evaluations. Their scores do not establish task difficulty.

From the repository root:

```sh
uv run pytest tests/tasks/test_spin_triangle_scoring.py tests/tasks/test_spin_triangle_lifecycle.py
uv run ruff check tasks/physical_sciences/frustrated_spin_triangle_yang_baxter_holonomy tests/tasks/test_spin_triangle_*.py
uv run ruff format --check tasks/physical_sciences/frustrated_spin_triangle_yang_baxter_holonomy tests/tasks/test_spin_triangle_*.py
```

The tests check author feasibility, incorrect calibrations, malformed controls,
hardware bounds, the mixed-channel tensor against an independent pair-sum
calculation, and the standalone checker. The lifecycle suite uses the real ALE
loader and cua-bench 0.2.7 with an in-memory session test double. It verifies
metadata, idempotent staging, hidden references, canonical grading, malformed
output and propagation of storage/internal errors. It is not a remote-provider
test. Missing or malformed answers score zero; infrastructure failures raise.

## Independent evaluation

Stage a fresh solver directory with:

```sh
uv run python tasks/physical_sciences/frustrated_spin_triangle_yang_baxter_holonomy/scripts/stage_blind.py /absolute/path/to/new/exam
```

The staging helper refuses an existing input or output directory, writes only
the four public inputs and an empty output directory, and prints SHA-256 hashes.
Give a fresh agent only that directory, with external references disabled and
an enforced time budget. Retain its transcript and score its answer using the
canonical host verifier. Report the model, budget, environment, score, and
number of fully passing scenarios. A failed bounded attempt is evidence of
difficulty for that protocol, not a proof that the task cannot be solved.

GPT-5.6-Sol at high reasoning completed five fresh offline Linux runs with a
3600-second solver allowance and 4-CPU/16-GiB container limits. Docker's shared
VM provides about 7.75 GiB RAM, so the memory limit is not guaranteed available
memory. The task inputs, rubric and solver instructions were unchanged across runs.

Mean across all five valid trials: **0.00 completion**, **0.20 diagnostic**.
After screening, lint-only checker cleanup removed a redundant integer cast,
parenthesized string concatenation and annotated the existing CLI error boundary.
The task statement, mathematical specification and numerical scenarios are unchanged.
Rescoring all five archived submissions reproduced every original result exactly.
All exited normally before their deadlines; no trial was excluded or replaced.
Every submitted schedule passed hardware, action, leakage and noise-cancellation
checks but failed target-gate fidelity. These are gate-synthesis failures, not
missing outputs, invalid JSON or infrastructure terminations.

All four public input hashes matched their launch values. The solver used only
the container execution interface; container networking was disabled and only
public inputs and output were mounted. NumPy, SciPy and g++ were preinstalled.
The generator and author answers were unavailable to the solver.

These five same-model trials support repeatable difficulty for this protocol;
classification remains with ALE. The twelve scenarios form one physics task,
not twelve independent model trials. Both completion and diagnostic scores are
reported to distinguish complete gate synthesis from partial cancellation progress.

These were custom container tests, not end-to-end ALE provider tests. The task
card now provides a 7200-second total lifecycle allowance for provisioning,
setup, solving and evaluation. Set experiment `wall_time_s: 3600` for the solver;
